Tutorial

-Press "Search for match" to search for a match

- When in a match, either you or your opponent will have a scramble. When it is your turn, press space to start inspection. Hold downspace for ~2 seconds to start the timer. Finally, press space again to stop the timer.

- After finishing your solve, make sure to select the penalty. Select OK if there is no penalty, +2 if there is a +2 second penalty, or DNF if there is a DNF penalty.
