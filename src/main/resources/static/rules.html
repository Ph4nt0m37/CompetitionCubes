Rules

  1. Follow all WCA rules and regulations.

    - Exception: Any penalties above +2 should be considered a DNF.

    - Exception: An inspection time +2 penalty will automatically be
       calculated, so a +2 can still be added on top of an inspection time penalty.

  2. Do not fake solves. Prematurely stopping the timer and not selecting
    the DNF punishment will result in a temporary or permanent ban.
  3. If you discover a glitch, do not abuse it. Doing so will
    result in a permanent ban.

    - Please report any bugs to the bug report form.
